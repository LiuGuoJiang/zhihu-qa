# 故事化写作技能

## 功能
将科技内容转化为引人入胜的故事形式，使复杂的技术话题变得易于理解且有趣。

## 使用方法
当Paperclip智能体调用此技能时，提供以下参数：

### 输入参数
```json
{
  "topic": "主题",
  "materials": [
    {
      "type": "素材类型",
      "content": "素材内容",
      "source": "来源"
    }
  ],
  "target_audience": "tech_enthusiast|general_public",
  "tone": "professional|casual|inspiring"
}
```

### 目标受众
- `tech_enthusiast`：科技爱好者，可以适当使用技术术语
- `general_public`：普通大众，需要更多解释和类比

### 语气风格
- `professional`：专业严谨，适合技术分析
- `casual`：轻松随意，适合经验分享
- `inspiring`：启发性强，适合趋势讨论

## 六段式故事结构

### 1. 钩子 (10%)
**目的：** 抓住读者注意力

**技巧：**
- 使用具体场景描述
- 提出反直觉问题
- 讲述令人惊讶的事实
- 营造紧张感或好奇心

**示例模板：**
- "上周深夜，我正准备睡觉，突然..."
- "你可能不会相信，但..."
- "这是我做过最错误的决定..."

### 2. 个人背景 (15%)
**目的：** 建立可信度和共鸣

**技巧：**
- 讲述相关经历
- 说明专业背景
- 展现真诚而非自夸

**示例模板：**
- "作为一个在X领域摸爬滚打N年的..."
- "我第一次接触X是在..."
- "说实话，我对X的理解经历了..."

### 3. 问题/挑战 (15%)
**目的：** 清晰描述要解决的问题

**技巧：**
- 用数据量化问题
- 说明问题影响
- 展现紧迫性

**示例模板：**
- "我们面临的最大问题是..."
- "数据显示，问题的严重程度在于..."
- "这个问题之所以重要，是因为..."

### 4. 探索过程 (25%)
**目的：** 展示解决问题的旅程

**技巧：**
- 按时间顺序叙述
- 包含失败尝试
- 展现学习曲线
- 保持真实性

**示例模板：**
- "我尝试的第一种方法是..."
- "起初我以为...但后来发现..."
- "这个过程中，我学到了..."

### 5. 解决方案 (25%)
**目的：** 给出清晰答案

**技巧：**
- 具体说明解决方案
- 提供数据支撑
- 解释原理
- 给出可操作建议

**示例模板：**
- "经过反复试验，我发现..."
- "关键在于..."
- "数据显示，这个方案的效果是..."

### 6. 关键收获 (10%)
**目的：** 总结和行动建议

**技巧：**
- 提炼3-5个要点
- 给出具体行动建议
- 鼓励互动

**示例模板：**
- "总结一下，如果你想..."
- "记住这三点：第一...第二...第三..."
- "你在自己的工作中遇到过类似情况吗？"

## 写作技巧

### 让技术通俗易懂
1. **使用类比**：将复杂概念与日常生活联系起来
   - "API就像餐厅的菜单..."

2. **避免术语堆砌**：必须使用术语时要解释
   - "所谓的容器技术，简单来说就是..."

3. **用具体例子**：用真实案例说明抽象概念
   - "比如，当我们在处理用户请求时..."

### 增强故事吸引力
1. **情感词汇**：适当使用情感词汇增强共鸣
   - "这让我彻夜难眠"
   - "我当时几乎要放弃"

2. **节奏控制**：长短句结合，保持阅读节奏
   - "短句有力。长句可以展开细节。"

3. **细节描写**：用具体细节增强真实感
   - 不是"用户增长很快"
   - 而是"用户数从1000增长到10万，只用了三个月"

## 质量检查清单
使用此技能生成内容后，检查：
- [ ] 是否遵循六段式结构
- [ ] 钩子是否吸引人
- [ ] 个人背景是否建立可信度
- [ ] 问题是否清晰
- [ ] 探索过程是否真实
- [ ] 解决方案是否清晰有数据支撑
- [ ] 是否有明确收获
- [ ] 技术解释是否通俗易懂
- [ ] 字数是否合理（800-1500字）
