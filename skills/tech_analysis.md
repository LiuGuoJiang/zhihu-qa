# 科技领域分析技能

## 功能
对科技产品、技术趋势、行业动态进行专业分析，为内容创作提供深度洞察。

## 涵盖领域

### 1. AI/LLM技术分析
- 模型能力评估
- 应用场景分析
- 技术趋势判断
- 竞品对比

### 2. 消费电子产品评测
- 产品功能分析
- 用户体验评估
- 市场定位分析
- 价格竞争力

### 3. 编程技术最佳实践
- 技术选型建议
- 架构设计分析
- 性能优化方案
- 开发流程改进

### 4. 科技行业动态
- 公司战略分析
- 人才趋势判断
- 市场机会识别
- 风险评估

## 分析框架

### 产品分析框架
```
1. 市场定位
   - 目标用户群体
   - 痛点解决
   - 竞争优势

2. 技术特点
   - 核心技术
   - 创新点
   - 技术壁垒

3. 竞争对比
   - 主要竞品
   - 差异化
   - 优劣势分析

4. 发展趋势
   - 技术演进方向
   - 市场预期
   - 潜在风险
```

### 技术趋势分析框架
```
1. 现状评估
   - 当前发展阶段
   - 主要玩家
   - 技术成熟度

2. 驱动因素
   - 技术突破
   - 市场需求
   - 政策环境

3. 应用场景
   - 已落地场景
   - 潜在场景
   - 场景成熟度

4. 发展预测
   - 短期趋势（1年内）
   - 中期趋势（1-3年）
   - 长期趋势（3年以上）
```

### 行业动态分析框架
```
1. 事件背景
   - 事件起因
   - 相关方
   - 时间线

2. 影响分析
   - 对行业的影响
   - 对用户的影响
   - 对竞争格局的影响

3. 深层原因
   - 表层原因
   - 深层逻辑
   - 结构性因素

4. 未来展望
   - 可能的发展方向
   - 不确定性因素
   - 关注要点
```

## 使用方法
当Paperclip智能体调用此技能时，提供以下参数：

```json
{
  "topic": "分析主题",
  "analysis_type": "product|trend|industry|technology",
  "focus_areas": ["重点关注领域"],
  "depth": "overview|detailed"
}
```

### 分析类型
- `product`：产品分析
- `trend`：趋势分析
- `industry`：行业动态分析
- `technology`：技术深度分析

### 深度级别
- `overview`：概览级，适合快速了解
- `detailed`：详细分析，适合深度内容

## 信息来源建议

### 官方信息
- 公司官方公告
- 产品文档
- 财报数据

### 权威媒体
- 36氪、虎嗅、极客公园
- TechCrunch、The Verge
- MIT Technology Review

### 专业社区
- GitHub趋势
- Hacker News讨论
- 知乎科技话题

### 研究机构
- Gartner、IDC报告
- 学术论文
- 行业白皮书

## 注意事项
1. 保持客观中立，避免偏见
2. 数据要注明来源
3. 区分事实和观点
4. 承认不确定性
5. 更新及时，确保信息时效性
