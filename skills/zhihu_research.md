# 知乎调研技能

## 功能
在知乎上搜索和分析科技相关的内容，支持问题发现、回答分析和趋势跟踪。

## 使用方法
当Paperclip智能体调用此技能时，提供以下参数：

### 输入参数
```json
{
  "query": "搜索关键词",
  "category": "问题分类（可选）",
  "filters": {
    "min_followers": 100,
    "max_followers": 5000,
    "min_answers": 5,
    "max_answers": 50,
    "min_views": 10000,
    "days_limit": 7
  }
}
```

### 问题分类
- `tech_ai`：人工智能、机器学习、深度学习
- `tech_programming`：编程技术、架构设计、最佳实践
- `tech_product`：产品评测、硬件软件
- `tech_industry`：行业动态、公司新闻、人才趋势

### 输出格式
返回符合条件的问题列表：

```json
{
  "results": [
    {
      "question_id": "问题ID",
      "title": "问题标题",
      "url": "问题链接",
      "excerpt": "问题摘要",
      "author": "提问者",
      "stats": {
        "followers": 关注数,
        "answers": 回答数,
        "views": 浏览数
      },
      "created_at": "创建时间",
      "category": "分类",
      "hot_score": 热度分数
    }
  ],
  "total": 返回结果数量,
  "search_time": "搜索耗时"
}
```

## 搜索技巧

### 关键词组合
针对科技领域，建议使用以下关键词组合：

**AI/LLM相关：**
- "GPT-4" + "应用"
- "大模型" + "落地"
- "AI Agent" + "实践"
- "RAG" + "架构"

**编程相关：**
- "微服务" + "最佳实践"
- "数据库" + "选型"
- "性能优化" + "经验"
- "代码审查" + "标准"

**产品相关：**
- "iPhone" + "评测"
- "新能源车" + "对比"
- "SaaS" + "增长"

### 筛选策略
1. 关注数在100-5000之间：竞争适中
2. 回答数在5-50之间：有讨论但未饱和
3. 发布时间在7天内：时效性强
4. 浏览数超过10000：有流量基础

## 注意事项
- 搜索时要注意时效性，优先选择最新内容
- 关注答主背景，优先考虑认证用户和专业领域答主
- 注意问题分类的准确性
